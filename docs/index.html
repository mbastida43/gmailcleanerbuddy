Why Gmail Cleaner Buddy

A small, self-hosted tool that does one thing well: find who is clogging your inbox and clear them out.

🔐

Secure OAuth2 login

Sign in with Google's official account picker. No passwords are ever seen or stored by the app.

🏆

Top 10 offenders

Instantly see the senders taking up the most space and message count in your mailbox.

🗑️

One-click cleanup

Move every email from a noisy sender straight to the trash with a single click.

🛡️

Privacy-first

Your data is never stored on any server. Everything runs in your own session, hardened per OWASP Top 10.

How it works

Run it locally in three steps — it's a lightweight Node + browser app.

Configure Google Cloud

Enable the Gmail API and create an OAuth 2.0 client. Full walkthrough in the instructions.

Install & run

Run npm install then npm start and open localhost:3000.

Sign in & clean

Sign in with Google, review the Top 10 senders, and hit Clean to reclaim space.

Under the hood

Roughly 1,400 lines of TypeScript, no database and no third-party backend.

🧩

TypeScript end to end

Server, browser client and this very page are written in TypeScript and compiled before they run.

⚙️

Node + Express server

A single server.ts drives the OAuth flow and exposes a small JSON API to the browser.

📮

Official Gmail API

Google's googleapis client lists your messages, groups them by sender and moves them with batchModify.

🚫

No database

Nothing is persisted: the access token lives in the server session and is gone the moment you sign out.

Built with security in mind

The app follows the OWASP Top 10 checklist documented in SECURITY.md.

🔑

One restricted scope

Only gmail.modify is requested — enough to read and to trash, nothing more. Your password is never seen.

🪖

Hardened HTTP

Helmet sets a strict Content-Security-Policy, HSTS in production, a locked-down Permissions-Policy and no-store on every API response.

⏱️

Short session, CSRF-checked

The signed httpOnly cookie lasts one hour — the same life as the Google access token — and every API call is verified as same-origin.

🚦

Rate limited

Up to 100 API requests and 10 sign-in attempts per 15 minutes, per IP address.

Good to know

A few honest limits before you run it.

🔍

Analyzes a recent sample

The scan covers your 500 most recent messages; exact totals are then fetched for the senders at the top.

⚡

Cleaning is bulk and fast

Messages are moved with batchModify, up to 1,000 per call — hundreds of emails clear in seconds.

♻️

Nothing is deleted forever

Emails are moved to the Gmail trash, where you can restore them for 30 days.

🧪

Testing mode by default

While the Google project is unverified, only accounts added as test users (up to 100) can sign in.
